# 历史行情局

> 把中国历史人物的一生，转化为一条可以比较、缩放和追溯依据的“生命行情”。

## 项目简介

历史行情局是一套面向中国历史人物的交互式叙事可视化系统。它把人物在不同年龄阶段拥有的权位、资源、联盟、军事能力、社会声望与生存处境，组织成 0—100 的「历史综合势能」，再以折线图和 K 线呈现人生中的上升、震荡、转折与传承。

你可以把刘邦与项羽放在同一条年龄轴上观察楚汉竞争，也可以跨时代比较韩信、李世民、王安石或近现代人物。光标靠近走势节点时，界面会吸附到真实事件点，并展示事件说明、影响维度、指数变化和史料入口；移动端则通过点按完成同样的探索。

项目不是给历史人物排名，也不把人生简单等同于股票。走势图是一种可解释的叙事工具：事实节点与来源索引负责提供依据，量化模型负责保持尺度一致，用户最终看到的是“为什么此时上升或下降”，而不只是一个孤立分数。

当前正式界面在 `src/v3/`，维护分支为 `rebuild/v2`。同一套数据提供两种主题：

- `#b` —「玉衡终端」：深色玉绿主题。
- `#c` —「朱砂长卷」：浅色纸本主题。

## 核心体验

- 300 位人物、2462 个历史事件，覆盖先秦至近现代。人物数据位于 `data/v2/figures/`。
- 同时代人物默认按纪年比较，跨时代默认按年龄对齐；支持手动切换、单人浏览和任意两人对比。
- 光标在节点上时显示「当时的势」，离开后回到「后世评价」；生前用实线，身后用虚线，后世时间段采用压缩展示。
- 折线 / K 线切换，红涨绿跌。缩放在全景、章节、细读之间切换，逐步展开事件、引文与来源。
- 宽屏事件详情停靠在绘图区上方，手机在图下方，避免挡住走势；支持鼠标吸附、点按固定和键盘浏览。
- 疆域地图作为走势背景，随光标所在人物与年份切换，帮助理解人物所在的时代。
- 「角色」页默认头像卡片墙，可按领域、时代及走势形态筛选；拖入 A / B 对比栏后进入主图。
- Ctrl / ⌘ K 搜索姓名、字号、代表概念和事件，按相关度排序；输入法选字时按回车不会误跳转。
- 自托管朝代字体、可读的中文小字、仅用于控件与浮层的玻璃效果，以及尊重 `prefers-reduced-motion` 的动效。
- 人物详情、头像与字体按需加载，资源失败可重试。浏览器缓存受限时继续走网络，避免把存储错误变成白屏。

## 数据声明

势能指数是解释性叙事模型，不是史学定论、道德评分、概率预测或可交易资产。哪些数字是程序算的、哪些是判断，事件理由与打分中有多少是模型生成的，见 [docs/MEASUREMENT.md](docs/MEASUREMENT.md)。300 位人物均关联原始/机构索引和人物辅助专页；联网审计覆盖 61/61 个来源索引与 300/300 个人物页。部分链接是典籍或馆藏的集合入口，正式史学出版仍应逐事件补充版本、卷次、页码与原文校勘。

## 前后端接口

本地 Vite 与线上 Worker 使用同一份接口实现：

- `GET /api/health`：服务状态、人物与事件总量、模型版本。
- `GET /api/figures`：人物库；支持 `q`、`period`、`dynasty`、`domain`、`offset`、`limit` 与 `compact=1`，并返回分页元数据。
- `GET /api/figures/:id`：单个人物及全部事件。
- `GET /api/compare?left=liubang&right=xiangyu`：双人年龄共轴走势、颜色与关键转折；加 `candles=1&target=liubang` 返回单人蜡烛数据。
- `GET /api/index`：时代、朝代与领域筛选分面。

接口响应包含 ETag；未变化的条件请求返回 `304 Not Modified`。非法分页参数返回结构化 `400`。

正式界面从随构建发布的轻量索引启动，再按人物加载独立 JSON；接口仍保留供集成使用。
