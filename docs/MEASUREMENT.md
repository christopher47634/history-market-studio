# 势能指数：口径、来源与主观成分

本文说明线上图表里每个数字从哪来、哪一部分是按规则算的、哪一部分是人（或模型）判断的。完整评分标准见 [`docs/v2/scoring-standard.md`](v2/scoring-standard.md)，代码版在 [`pipeline/rubric.mjs`](../pipeline/rubric.mjs)。

> 势能指数是**解释性叙事模型**，不是史学定论、道德评分、概率预测或可交易资产。

## 1. 两种分数

| 分数 | 衡量什么 | 不衡量什么 |
|---|---|---|
| **势**（生前曲线、K 线） | 此人在那一刻的地位、实力与处境 | 后人怎么评价他 |
| **后世评价**（身后声望线终点） | 此人在历史上的分量 | 褒贬。褒贬另用「正面 / 争议 / 负面」标签 |

封顶：毛泽东是唯一的 100 分锚点，其余人物两种分数最高都是 98。

## 2. 哪些是算出来的，哪些是判断出来的

| 环节 | 方式 | 主观程度 |
|---|---|---|
| 生卒年、事件年份、年龄 | 取通行说法；无确载的标「估计」 | 低。存疑处已标注 |
| 选权位档（布衣…天下共主） | 判断：按官位、实力、名望落档 | **中**。档的定义写死，但「这算不算一方之主」需要判断 |
| 档内定位（档分） | 判断：在档位区间内取值 | **高**。同一档内的高低没有客观尺子 |
| 选危局（平稳 / 受挫 / 大败 / 绝境）与折损 | 判断：按处境分类，折损在区间内取值 | **中** |
| 势 = max(2, 档分 − 折损) | **程序计算** | 无 |
| 终章 = 前一阶段 × 保留率 | 保留率（0.80–1.00）是判断，乘法是程序算 | 中 |
| 后世评价档位与分数 | 判断：综合影响广度、深度、持续时间、后世共识 | **高** |
| 身后事件分数 | 判断：那个时间点此人被记住、被重视的程度 | **高**；没有明确身后事件的人物用平滑线推算 |

也就是说，**程序保证的是「尺度一致」，不保证「判断正确」**。同样的档位和折损一定算出同样的势；但选哪个档、给多少后世评价，仍是一家之言。

## 3. 证据分级

每个节点都标了依据，界面上的详情卡会显示（`src/v3/bits.jsx`）：

| 标签 | 含义 | 数量（2,462 个节点） |
|---|---|---|
| 史书原文 | 引句逐字出现在维基文库的史书原文里，由 `pipeline/build.mjs` 自动核对 | 1,430 |
| 维基百科 | 近现代人物没有正史，引句逐字出现在固定版本的中文维基条目里 | 417 |
| 概括 | 找不到可核验的原句，节点内容是概括 | 615 |

其他需要知道的数字（来自 `data/v2/client/`，可用 `npm run test:schema` 复核）：

- 217 个节点的年份是「估计」；79 位人物的生年、21 位的卒年是估计值。
- 终章 300 个，其中 124 个有核验过的原句，176 个是概括。
- 身后事件 515 个，其中 174 个是「推算」（没有明确身后事件，平滑过渡到后世评价），界面上画得更淡。
- 17 位人物没有可链接的来源，所有节点都是「概括」。
- 68 个身后事件还没写打分理由，`npm run test:schema` 会列为提醒。

**核验只证明「这句话确实在原文里」，不证明打分合理。**

## 4. 数据是怎么生成的

1. 人物、事件和档位由模型（DeepSeek，`pipeline/extract.mjs`；部分由 Claude 手写，`pipeline/author.mjs`）或人工起草。起草时只让模型选档、选危局、在档内定位、写理由，**最终数字由程序算**。
2. `pipeline/build.mjs` 按 `rubric.mjs` 算分，逐字核对引句：找不到原句的降为「概括」，不冒充原文。
3. 部分人物用模型做过一次盲打分复核（`data/v2/rescore/`）。起草与复核相差超过 8 分的事件，由 Claude 按评分标准逐条裁定（`data/v2/adjudications.json`），也是模型判断，不是人工。
4. 16 位锚点人物的数值写在评分标准第 4 节，其余人物以它们为参照。
5. 审核表由 `pipeline/review.mjs` 生成，见 `docs/v2/review.md`；近现代人物另有 `docs/v2/modern-review.md`。

所以，**事件理由、摘要和打分判断里有大量模型生成的内容**。有审核表可供抽查，但没有逐条人工校勘。

## 5. 自动校验守住了什么

`npm run test:schema`（`scripts/validate-schema.mjs` + `src/v2/clientSchema.js`）对 300 个人物文件逐项检查：

- 字段齐全、类型正确，枚举值（档位、危局、证据、确定度、褒贬标签）只能取登记过的值；
- 档分落在档位区间、折损落在危局区间、势 = max(2, 档分 − 折损)；
- 年龄 = 事件年份 − 生年（跨公元前后没有 0 年）；
- 终章保留率在 0.80–1.00，且终章 = 前一阶段 × 保留率；
- 后世评价落在档位区间、不超过封顶，身后声望线终点等于后世评价；
- 标为「原文」的节点必须带引句。

`npm run test:data` 另外检查界面拿到的结构、引句数量、覆盖面和对比逻辑。

## 6. 已知局限

- 档内定位、后世评价、身后分数没有可复现的客观依据，换一个人打分会不同。
- 「天下共主」「一方之主」等档位对分裂时期、少数民族政权、非政治人物的适用性有争议。
- 来源链接部分是典籍的集合入口；正式史学用途仍需逐事件补版本、卷次、页码。
