# 近现代 43 人复核记录（2026-10-01）

近现代人物没有正史，引句来自中文维基百科。这批数据由一人起草，所以单独做了三道复核：跨人物一致性、敏感措辞、来源固定。

## 1. 跨人物一致性

工具：`npm run v2:audit`（`pipeline/audit-consistency.mjs --modern`）。

做法：按职位或处境给事件归类，共 17 类，如留学、院士、大学校长、部长、院长、被捕、下放批斗、回国等。每类算出近现代同类事件的档内分中位数和折损中位数，偏离超过 8 分（折损超过 20 分）的标出来，再逐条裁定。

结果：标出 54 条，其中 45 条维持原分，9 条改分。

**维持原分的理由**：同类事件的分数本来就随本人当时的地位不同。例如钱学森 1955 年回国时已是国际知名学者，与詹天佑 1881 年学成回国被冷遇，不应同分。「势」衡量的是此人当时的权位与处境，不是事件本身的分量。

**改分的 9 条**：

|---|---|---|---|---|

## 2. 敏感措辞

列出所有涉及文革、反右、整风、清党、林彪、1989 等的近现代节点，共 40 条，逐条通读。原则：只写可查证的事实；评价性的话交给「后世评价」，不放进事件描述。

改了 4 处：

- **李四光 1966**：标题「周恩来保护」改为「文革中受到保护」。标题应写事件本身，不应写评语。
- **钱伟长 1957**：概要「下放」与事实不符，改为「撤销清华副校长等职务，教学科研受限」。
- **茅以升 1966**：「反动学术权威」是当时扣的帽子，加引号写成「被扣上『反动学术权威』帽子」，不作陈述句。
- **邓小平 1989**：改为按事实陈述「十三届五中全会同意其辞去中央军委主席，完全退休」。

## 3. 来源固定与署名

- `npm run v2:pin-wiki` 在同一次请求里取条目正文和版本号，正文写回 `data/v2/sources/<id>/wiki.txt`，版本号记在 `data/v2/wiki-revisions.json`。
- 出处链接一律用 `oldid` 永久链接，出处名带版本日期，例如「维基百科「周恩来」（2026-09-30 版）」。条目以后被修改，链接仍然打开当时核对的那一版。
- 换成固定版本后重新逐字核验，447 句百科引句全部仍能对上。
- 页脚注明维基百科内容按 CC BY-SA 4.0 使用，`test:data` 会检查每个维基来源都带 `oldid` 和许可证。
