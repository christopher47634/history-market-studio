# 历史行情局 v2 · 评分标准（阶段 0 草案）

状态：待用户审核。审核通过后，全部人物按本标准重打分，锚点人物的数值作为其他人物的参照。

## 1. 两种分数

| 分数 | 含义 | 在哪里出现 |
|---|---|---|
| **势**（生前曲线） | 这个人在那一刻的地位、实力与处境。只看当时，不看后人评价。 | 生前折线、K 线；光标落在某点时的读数 |
| **后世评价** | 这个人在历史上的分量。 | 身后声望线的终点；光标不在图上时的读数 |

两种分数都跨人物可比：刘邦的 90 和李世民的 90 是同一个分量。

后世评价衡量的是「分量」，不是褒贬。秦始皇争议很大，但分量极重。褒贬另用标签表示：正面、争议、负面。

## 2. 势的计算

**势 = 权位档分 − 危局折损**，最低为 2。

模型只负责选档位和危局、在档内定位并写理由，最终数字由程序计算。

### 2.1 权位档

| 档位 | 分数 | 政治、军事 | 文化、思想、科技 |
|---|---|---|---|
| 天下共主 | 95–100 | 统一或主宰天下的君主。100 只给统一之主。 | 生前到不了这一档 |
| 一方之主、中枢首辅 | 85–94 | 割据政权之主、摄政、宰相、首辅 | 同时身居相位者 |
| 重臣、主帅 | 70–84 | 统率一方大军、中央重臣 | 当世宗师且居高位 |
| 方面、名家 | 55–69 | 地方大员、偏师将领 | 名满天下的文坛或学派领袖 |
| 成名 | 40–54 | 州郡官员、重要幕僚 | 有文名、学名而无大位 |
| 初起 | 25–39 | 小吏、刚起兵 | 小有名声 |
| 布衣 | 8–24 | 未发迹 | 未成名 |

出生分按家世定：皇族约 35，贵族、官宦约 25，平民约 12，贫寒约 8。

### 2.2 危局折损

| 处境 | 折损 |
|---|---|
| 平稳 | 0 |
| 受挫（贬官、小败、被排挤） | −5 到 −15 |
| 大败、失地、罢黜 | −20 到 −35 |
| 被围、下狱、受刑、流放 | −40 到 −60 |

例：项羽在垓下，档位是西楚霸王约 90 分，被围折损 60，结果为 30。

### 2.3 终章（沿用用户 2026-08-02 定的规则）

- 终章 = 前一有效节点的势 × 保留率，保留率在 0.80–1.00 之间。
- 保留率看制度、政策、作品、思想在死后是否延续。
- 死亡不归零。终章只承接生前处境，身后的升降交给身后声望线。

## 3. 后世评价

| 档位 | 分数 | 标准 |
|---|---|---|
| 文明塑造者 | 95–100 | 改变中华文明走向，影响延续两千年以上 |
| 时代定义者 | 85–94 | 一个时代或一个领域的最高代表 |
| 一代名臣、名将、名家 | 75–84 | 领域内公认的顶尖人物 |
| 重要人物 | 60–74 | 对本朝或本领域有显著影响 |
| 有影响 | 45–59 | 在专门史里占有一席 |
| 局部 | < 45 | 影响限于一时一地 |

打分时综合四项：影响广度、影响深度（是否改变制度、思想、文体）、持续时间、后世共识程度。

### 身后声望线

- 从终章开始，按身后事件（平反、追封、被尊崇、被清算、被重新发现）画到今天。
- 终点等于后世评价。
- 没有明确身后事件的人物，用一条平滑线从终章过渡到后世评价，画得更淡，并标注「推算」。

### 请重点看这几处

1. **孔子**：生前峰值 65，后世评价 100。这是「当时的势」和「历史分量」差距最大的一例，也是这套标准的意图所在。
2. **项羽**：峰值 94，比刘邦称帝低 3 分。理由是分封天下时已是实际的天下主宰，但没有统一。
3. **韩信**：峰值 88。齐王属于一方之主，比项羽、刘邦都低。
4. **诸葛亮**：峰值 88，低于曹操的 93。理由是蜀汉只占三分之一的天下。
5. **杜甫**：一辈子没超过 45 分，身后涨到 93。要不要这种反差，是决定标准松紧的关键。

## 5. 横轴规则

- 两人生命有重叠时，默认用公元纪年，可以一键切回年龄。
- 两人生命没有重叠时，只能用年龄。
- 身后声望线只在公元纪年轴上画到今天。在年龄轴上，身后部分压缩成终章之后的一段尾巴，并标注「身后」。
