# 朝代字体的来源与许可

这些文件是对下列开源字体的子集化版本（只保留本站用到的字，转成 WOFF2），按许可要求改名为 HMS ×××。

- HMS Brush ← Ma Shan Zheng（马善政毛笔楷书）https://github.com/googlefonts/mashanzheng，许可：OFL-1.1
- HMS Xing ← Zhi Mang Xing（志莽行书）https://github.com/googlefonts/zhimangxing，许可：OFL-1.1
- HMS Xiaowei ← ZCOOL XiaoWei（站酷小薇）https://github.com/googlefonts/zcool-xiaowei，许可：OFL-1.1
- HMS Kai Medium ← LXGW WenKai Medium（霞鹜文楷 中粗）https://github.com/lxgw/LxgwWenKai，许可：OFL-1.1
- HMS Kai ← LXGW WenKai（霞鹜文楷）https://github.com/lxgw/LxgwWenKai，许可：OFL-1.1
- HMS Ming ← LXGW Neo ZhiSong（霞鹜新致宋）https://github.com/lxgw/LxgwNeoZhiSong，许可：IPA-1.0

改动：仅子集化与格式转换，未改动字形。原始字体可从上面的地址获取。
OFL 1.1 全文见 OFL.txt；IPA Font License 1.0 全文见 IPA-LICENSE.md。
